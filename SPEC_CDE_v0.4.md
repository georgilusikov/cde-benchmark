# CDE v0.4 specification

CDE is a conditional discovery algorithm, not a universal criterion list: MINI-FRAME; TASK MODE (SPEC/SELECT/AUDIT); qualitative TRIAGE; QUALITY ROUTER; EVIDENCE POLICY; PRIORS; conditional DISCOVERY DELTA; strict OBJECTIVE/REQUIREMENT/MEASURE/TEST/RISK/ASSUMPTION structure; provenance; meta-validation; sequential decision reduction; independent judge where warranted; regime-dependent output; learn.

The benchmark operationalizes the safety constraints: no numeric importance score, no automatic multi-agent or lifecycle requirement, normative requirements cannot be ignored because they seem small, LLM hypotheses cannot create hard gates, and interaction must be checked before deletion.
